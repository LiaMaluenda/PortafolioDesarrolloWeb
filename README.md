# Portafolio web · Lia Maluenda

Portafolio profesional desarrollado como entrega final del módulo **Desarrollo de portafolio de un producto digital**.

🔗 **Sitio publicado:** https://liamaluenda.github.io/PortafolioDesarrolloWeb/

## Contenido
- Inicio y presentación profesional
- Sobre mí
- Experiencia laboral, formación académica y certificaciones
- Habilidades: lenguajes, frameworks, bases de datos y herramientas
- Proyectos del curso (Vue Product Showcase, TaskFlow y SmartBudget) con problema, rol, tecnologías, resultados y enlaces a demo y repositorio
- Contacto (formulario con validación y enlaces a GitHub y LinkedIn)

## Tecnologías
- HTML5 semántico
- CSS3: variables (custom properties), Grid, Flexbox, diseño mobile first
- JavaScript (sin librerías)
- GitHub Pages

## Funcionalidades
- Modo claro y oscuro: respeta la preferencia del sistema y recuerda la elección de la persona
- Menú responsivo accesible (teclado, `aria-expanded`, cierre con Escape)
- Resaltado de la sección visible en el menú
- Formulario de contacto con validación accesible y envío de los mensajes a Google Forms
- Respeta `prefers-reduced-motion`
