SPA · Módulo 7

Vue Product Showcase

Catálogo de productos que consume FakeStoreAPI, con filtros combinables, favoritos y modo claro/oscuro.

  • Vue 3
  • Vuex 4
  • Vuetify 3
  • Axios
  • Jest
  • Cypress
Problema
Mostrar un catálogo traído desde una API y permitir filtrarlo por categoría, nombre y favoritos a la vez, sin que los componentes pierdan sincronía entre sí.
Mi rol
Desarrollo individual completo: componentes, estado con Vuex, consumo de la API, pruebas automatizadas y documentación.
Resultado
SPA con 4 componentes y 3 módulos de Vuex, precios en pesos chilenos, categorías en español, alerta cuando la API falla y 3 de 3 pruebas aprobadas (2 unitarias y 1 E2E).
Aprendizaje
Separar componentes presentacionales (props y eventos) de la lógica de estado, y diseñar pruebas que no dependan de internet.
Ver demo Repositorio

Aplicación web · Módulo 5

TaskFlow

Gestor de tareas en JavaScript puro con fechas límite, búsqueda en vivo y sincronización con una API REST.

  • JavaScript ES6+
  • POO
  • Fetch API
  • localStorage
  • CSS3
Problema
Organizar tareas personales sin perderlas al recargar la página, saber cuánto falta para cada plazo y poder sincronizarlas con un servidor.
Mi rol
Desarrollo individual: modelo de datos con clases, lógica de eventos, conexión con la API y estilos.
Resultado
Crear, completar y eliminar tareas; contador de caracteres y filtro en vivo; cuenta regresiva por segundo; avisos que desaparecen a los 2 s; GET y POST a JSONPlaceholder y guardado en localStorage.
Aprendizaje
Programación orientada a objetos (clases Tarea y GestorTareas), delegación de eventos, async/await con manejo de errores y temporizadores.
Ver demo Repositorio

Landing page · Módulo 3

SmartBudget

Landing de una app de finanzas personales, construida a partir de un prototipo de alta fidelidad en Figma.

  • SASS / SCSS
  • BEM
  • Arquitectura 7-1
  • Bootstrap 5
  • JavaScript
  • Figma
Problema
Llevar un diseño de Figma a código manteniendo los estilos ordenados y fáciles de escalar a medida que la página crece.
Mi rol
Desarrollo frontend individual: maquetación semántica, arquitectura de estilos, personalización de Bootstrap e interacciones.
Resultado
Página publicada con hero, maqueta de dashboard, funciones, pasos, testimonios y precios. Estilos divididos en carpetas abstracts, base, components, layout, pages, themes y vendors.
Aprendizaje
Nombrar clases con BEM, usar variables y parciales de SASS y sobrescribir variables de Bootstrap en lugar de pelear contra sus estilos.
